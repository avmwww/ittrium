# GD32F350 example

Cortex-M4 board example using the GD32F3x0 firmware library.

## Dependencies

```bash
export GD32_FW=<path to https://github.com/DmitryTyazhlov/GD32F3x0_Firmware_Library_V2.3.0>
```

Example:

```bash
export GD32_FW=~/GD32F3x0_Firmware_Library_V2.3.0
cd example/gd32f350
make clean
make
```
